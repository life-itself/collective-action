## Game-theory check (matrices and equilibria)

Recomputed each matrix. All ordinal payoffs match the stated orderings and all equilibria are right.

- PD (T > R > P > S): D strictly dominates; unique (D,D); no mixed equilibrium. Correct.
- Stag hunt (4/1/3/2 as R/S/T/P): equilibria (stag,stag) and (hare,hare); mixed at 1/2 with these numbers (3p+1 = p+2). Correct. Chapter 1 numbers (4,4 / 0,3 / 3,0 / 3,3): mixed at stag 3/4; hare is risk-dominant (deviation losses 1 vs 3). Correct. Note that the 1/2 uses the ordinal numbers as cardinal; the notes say "with these numbers".
- Chicken (3,3 / 2,4 / 4,2 / 1,1): equilibria (C,D), (D,C); mixed 1/2 each (p+2 = 3p+1); crash probability 1/4. Correct.
- Volunteer, n = 2, U = 4, K = 1: matrix is T > R = S > P, not strictly ordinal (tie R = S), as the notes say. Pure equilibria: exactly one volunteer. Mixed: q = (K/U)^(1/(n-1)); n = 2 gives q = 1/4 and nobody-acts 1/16; n = 10 gives q = 0.857 and nobody-acts 0.214; limit K/U = 0.25. All correct, and consistent with Diekmann as described by secondary sources.
- Pure coordination: mixed 1/2. Mozart/Mahler (2,2 / 1,1 / 0 off-diagonal): Mozart with probability 1/3. Correct and matches O&R Fig. 16.2.
- BoS: mixed ((2/3,1/3),(1/3,2/3)), payoffs (2/3,2/3), below both pure equilibria. Correct and matches O&R Ex. 34.1 and Ex. 46.1.
- Deadlock (T > P > R > S) and harmony (R > T > S > P): D dominates in deadlock, C in harmony. Correct; both match Heckathorn Table 2 orderings.
- Greed/fear grid: PD = greed and fear; chicken = greed only; stag hunt = fear only; harmony = neither. Correct for R > P. The "no greed, no fear" cell holds five orderings (including S > R), all with C dominant or no dilemma, so "harmony" is a fair label.
- One more check: the notes' Hawk-Dove ESS remark (row 25) and the war-of-attrition remark (row 22) are the only game-theory statements stated without their conditions.
