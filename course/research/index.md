# Example candidates — review index

Everything the four candidate hunts turned up: **120 candidates**. One line
each, grouped by list and by section, so the whole set can be read in one pass.

Each line is: the case, what it illustrates, and whether usable media is known.
Follow the link for the full entry with sources and the diagnostic.

How to use this: mark the ones you want. The selection becomes the working set,
and only then do per-example research and media beads get created (bead
`moloch-dhe.5`).

Flags: **[C]** the account is contested — read the entry before using.
**[M]** strong media known. **[?]** a detail is unverified.
